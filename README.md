# stock-trade-simulator
Stock trading simulator with margin trading and real-time market data.

Created by **hanheita38**

## 概要
このアプリは、株式投資を学ぶための非営利の**教育用トレードシミュレーター**です。
リアルタイムに近い市場データを使用して、リスクなしでトレーディングの練習を行うことができます。

## 特徴
- リアルタイム株価に基づくシミュレーション
- 完全に無料、広告なし
- ユーザーのプライバシーを重視（データはすべてブラウザのローカルストレージに保存されます）

## 使い方
このアプリを使用するには、**Finnhub.io** で発行される無料のAPIキーが必要です。
1. [Finnhub](https://finnhub.io/) で無料アカウントを作成し、APIキーを取得してください。
2. アプリの設定画面で取得したAPIキーを入力してください。
3. すぐにシミュレーションを開始できます。

## Overview
This app is a non-profit **educational trading simulator** for learning about stock investing.
It allows you to practice trading risk-free using near real-time market data.

## Features
- Simulation based on real-time stock prices
- Completely free, no ads
- User privacy is prioritized (all data is stored in your browser's local storage)

## How to Use
To use this app, you need a free API key issued by **Finnhub.io**.
1. Create a free account at [Finnhub](https://finnhub.io/) and obtain an API key.
2. Enter the obtained API key in the app's settings screen.
3. You can start the simulation immediately.
